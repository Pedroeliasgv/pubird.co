## 🧠 Sobre o projeto

A **Pubird** é uma landing page de alta conversão desenvolvida para apresentar serviços de crescimento digital com foco em:

- 📈 Tráfego pago
- ⚙️ Automação de processos
- 📊 Análise de dados
- 🎯 Estratégia de aquisição

O projeto foi construído com foco em **performance, design premium e conversão**.

---

## ✨ Principais funcionalidades

- 🔥 Hero Section com animações e layout premium
- 🎯 CTA estratégico para captura de leads
- 📊 Simulação de dashboard de crescimento
- 📩 Integração com Supabase (armazenamento de leads)
- 📱 Layout totalmente responsivo
- 🎨 Design system com TailwindCSS

---

## 🛠️ Tecnologias utilizadas

- ⚛️ React + Vite
- 🎨 TailwindCSS
- 🧩 shadcn/ui
- 🗄️ Supabase (backend & database)
- 🔐 Environment Variables (.env)
